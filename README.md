# PHYS 2550 Homework 1

Linear regression from scratch on the UCI Real Estate Valuation data set
(414 houses in Taipei), using only NumPy and matplotlib.

- `homework1.ipynb` runs from the top without errors.
- `Real estate valuation data set.csv` is the data, converted from the
  original XLSX. The notebook downloads it automatically if it is not
  already in the working directory, so the notebook also runs on Colab.

Data source:
https://archive.ics.uci.edu/dataset/477/real+estate+valuation+data+set
